# Rock-Paper-Scissors

Inserir uma das opções propostas: pedra re ou tesoura
Atribuir um valor para cada elemento
Atribuir os valor que seerao gerados pelo computador

IF se os numeros gerados forem menor ou igual a dois o valor é pedra;
IF se os numeros gerados forem maior que dois e menor que seis o valor é papel;
ELSE do contrário o valor será tesoura
